### ⭐ Featured Project — AGP × Alllab

**AGP — AI Workflow Orchestration, Governance & Quality Assurance**

AGP is my evolving personal framework for coordinating AI-assisted projects. Alllab serves as a version-controlled knowledge and rules hub. The goal is to make collaboration across tools more traceable, cost-aware, and verifiable, while keeping humans responsible for authorization and high-risk decisions.

| Focus | What I am developing |
| --- | --- |
| **Task planning and coordination** | Break requests into trackable tasks and select appropriate tools without assuming that every tool is already connected or automated. |
| **Incremental development** | Inspect existing work first and use **KEEP / REUSE / FIX / ADD** decisions to make the smallest necessary changes without losing previously verified functionality. |
| **Evidence-based quality assurance** | Separate documentation, source-code readiness, automated tests, and real-environment verification. Use the **G0–G5** workflow to track changes, tests, and delivery. |
| **Authorization and privacy** | Preserve human oversight for sensitive operations and keep private data, confidential instructions, and public deliverables separate. |
| **Cost-aware execution** | Prioritize existing tools and lower-cost approaches, evaluating local and cloud AI resources according to task requirements. |
| **Knowledge continuity and handoffs** | Use versioned documents, rule indexes, task records, and handoff notes to reduce context loss between tools and work sessions. |

**Status:** This is an evolving engineering framework. Documentation and workflow rules are being developed and refined. Individual integrations, automation capabilities, and Windows desktop behavior require their own verification. **It is not presented as a fully deployed autonomous AI-agent platform.**

**Public scope:** This profile shares design concepts, methods, and high-level outcomes only. Private Alllab rules, source code, credentials, and user or client data remain private.

### 關於我

我擁有超過 13 年的建築製圖與室內 3D 視覺化經驗，工作涵蓋客戶需求理解、空間建模、視覺品質檢核，以及設計提案成果交付。

### ⭐ 重點專案 — AGP × Alllab

**AGP — AI 協作工程、任務治理與品質驗收工作流程**

AGP 是我持續建立的個人 AI 協作專案方法與工程規範體系，使用 Alllab 作為版本化規則與知識中心。目標是讓跨工具協作更可追蹤、重視成本且具備可核對的驗收紀錄，同時保留人對授權與高風險決策的控制。

| 核心設計 | 正在建立的能力 |
| --- | --- |
| **任務規劃與協作** | 把需求拆解成可追蹤任務，依工作選擇合適工具，不假設所有工具都已接線或能自動化。 |
| **先整合後開發** | 先核對既有成果，再依 **KEEP / REUSE / FIX / ADD** 做最小必要修改，避免破壞已驗收功能。 |
| **證據導向驗收** | 區分文件、原始碼準備、自動測試與真實環境驗收，以 **G0–G5** 流程追蹤變更、測試與交付。 |
| **授權與隱私** | 敏感操作保留人工把關，將私人資料、機密指示與公開交付物區隔。 |
| **成本控制** | 優先利用已有工具與低成本方案，按任務需求評估地端及雲端 AI 資源。 |
| **知識延續與交接** | 透過版本化文件、規則索引、任務紀錄及交接筆記，降低跨工具與跨工作階段的上下文流失。 |

**目前狀態：** 這是持續迭代中的工程體系；文件與流程規則正在建立及完善。各項工具串接、自動化能力與 Windows 實機行為仍須逐項驗證。**不宣稱已部署成完整自主運作的 AI Agent 平台。**

**公開範圍：** 本頁只展示設計概念、方法及成果摘要。Alllab 私人規則、原始碼、帳密與使用者／客戶資料均不公開。
