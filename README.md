## ⭐ Featured Project｜AGP × Alllab

### AGP｜AI 協作工程、任務治理與驗收工作流程
**AI Workflow Orchestration, Governance & Quality Assurance**

AGP 是我持續建立的**個人 AI 協作開發方法與工程規範體系**，以 Alllab 作為版本化規則與知識中心，協助不同 AI 工具在明確授權與驗收標準下執行專案。

AGP is my evolving framework for coordinating AI-assisted work through versioned guidance, clear authorization boundaries, and evidence-based quality checks.

| 核心設計 / Focus | 公開說明 / What it does |
| --- | --- |
| **任務拆解與協作** · Task orchestration | 將需求轉換為可追蹤工作項目，按任務選擇合適工具；不假設所有工具已自動串接。 |
| **先整合後開發** · Incremental development | 盤點既有成果，依 **KEEP / REUSE / FIX / ADD** 決定最小變更，避免覆蓋已驗收功能。 |
| **分層驗收** · Evidence-based QA | 區分文件／原始碼、測試通過與真實環境驗收；以 **G0–G5** 流程記錄差異、測試和交付。 |
| **授權與隱私** · Human oversight | 保留高風險操作的人工決策，隔離私人資料、機密內容與公開成果。 |
| **成本控制** · Cost-aware execution | 優先利用既有工具及低成本方案，按需求評估本地與雲端模型。 |
| **知識與交接** · Reproducibility | 使用版本化文件、規則索引、工作紀錄及交接資訊，降低跨工具工作的上下文遺失。 |

**目前狀態 / Status：** 工程規範與工作流程持續迭代；各工具接入、自動化與 Windows 實機驗收依個別功能進度核實。**這是開發中的體系，不代表已完成全自動 AI Agent 平台。**

**公開範圍 / Public showcase：** 這裡展示設計理念、方法與成果摘要。Alllab 內部規則、私人專案原始碼、授權資訊及使用者資料不公開。
